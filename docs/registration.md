# Player registration

## Before guests arrive

1. Open `Domino-Night.html` in Chrome or Edge, or start **Open Tracker.cmd** and open <http://127.0.0.1:8765/Domino-Night.html>.
2. Use the organizer page. The address ending in `?tv=1` is a read-only display and cannot register players.
3. Open **Players**. Enter the event name and number of available tables.
4. If an old or practice event already has a schedule, **Export backup** if needed, then select **Start new event**. This keeps the names but clears rounds and results.

## As people arrive

- Set **Player count** and click **Apply count** to adjust the placeholder slots.
- Enter one player per line in the names box. Use real names or nicknames that uniquely identify each person. No email addresses or accounts are needed.
- You may paste a full list instead of using the count control. The app uses the number of nonblank names in the list.
- Click **Save names** after each batch. Saving does not lock registration.
- Wait until attendance is final before generating the schedule.

For example:

```text
Alex R.
Alex M.
Casey
Jordan
```

That is a formatting example; the event needs at least eight players. The maximum is 48.

## Close registration

1. Count the players physically present and check that the saved list matches.
2. Check the available table count.
3. Click **Generate qualifying rounds** and review the confirmation.
4. Print all rounds from **Qualifying rounds** and print the current rules from **Rules & help**.
5. Announce who has a bye and where each player sits for round one.

You do not need a multiple of four players. The app assigns rotating byes and ranks by win percentage, then average points. A bye earns no win, loss, or points and does not count toward the four-game total. Extra rounds ensure everyone plays exactly four matches. With six tables and more than 24 players, a round may need more than one wave of games.

## Corrections and late arrivals

**Spelling correction:** Change the player's name on its existing line and select **Save names**. Do not move that line or rearrange the list.

**A player joins or leaves before the first game:** Export a backup, select **Players → Start new event**, adjust the list, save, and generate new rounds. Replace any printed schedules with the new ones.

**A player joins or leaves after play starts:** The current version does not support safely changing the roster mid-event while retaining its results. Do not overwrite an existing player's name with a different person's name, since this would transfer their results. Keep the field fixed, or explicitly restart the event after exporting a backup.

## During play

Players report scores to the organizer; they do not register or score through a public link. Keep only one organizer tab open. The TV window is read-only and should run in the same browser/profile on the same computer. Export a backup after every round.
